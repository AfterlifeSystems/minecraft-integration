# Play with the avatar

You already have Minecraft Java and Fabric.

1. Open the `mods` folder on this computer (the same folder that already has Fabric API).
2. Copy the jars from the adult's `minecraft-integration/mods` folder into that `mods` folder.
3. Start the Fabric 1.21.1 profile.
4. Multiplayer. Type the address the adult wrote down.
5. Hold **V** and talk. The other person in the world is the avatar.
